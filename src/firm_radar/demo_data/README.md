# Demo seed data

Every identifier here is fictional. The KRS number `0009999901` is far above the range the
National Court Register has issued, and the NIP `1234563218`, REGON `123456785` and buyer
NIP `1111111111` are documentation samples that only satisfy the checksum rules. They are not
guaranteed to be unassigned, so do not treat them as belonging to anyone. The response
structure follows the real APIs; the values do not describe a real entity.
